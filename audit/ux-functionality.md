# Replay Mathematics — сценарии, UX и доступность

Экспертная проверка по [10 эвристикам Nielsen Norman Group](https://www.nngroup.com/articles/ten-usability-heuristics/) и [описанию метода NN/g](https://www.nngroup.com/articles/how-to-conduct-a-heuristic-evaluation/). Это инспекция и браузерные прогоны с одной тестовой базой, не наблюдение за школьниками. Ориентир в пять секунд не измерялся. Для доступности проверены конкретные критерии [WCAG 2.2](https://www.w3.org/TR/WCAG22/), а не всё соответствие AA.

## Выполненные сценарии и критерии

- Из каталога первый вопрос открывается одним действием («Задачи»); путь через урок — двумя, без учёта ответа. Проверены выбор класса, запуск по коду `linear:0`, корректный ответ `-5`, недопустимая дробь, пропуск с обратной связью, завершение практики, отметка урока и сохранение после перезагрузки, переход к повтору, часть тура и ручной уход из него. 23 штатных Python теста прошли; не все критерии покрыты.
- Клавиатурой достигались ссылки, тест и числовое поле, обработка Enter работала. При переходах фокус как минимум в проверенном уроке оказался на H1; отдельная проверка фокуса на ошибке дала проблему №12. Это выборочная проверка 2.1.1, 2.4.3 и 2.4.7. Полный маршрут со скринридером и 400% браузерным масштабом не проходил.
- При 320 CSS px проверены тест и два урока, измеренный scrollWidth не превышал доступную ширину 305 CSS px. Это выборка 1.4.10, не проверка всех страниц. Основные ссылки шапки в выборке были 39 px высотой и не меньше 35 px шириной; это не даёт вывода по всем целям 2.5.8. Основные пары текста #252725 / #ffffff и #565b55 / #f5f4f0 дают 15,05:1 и 6,31:1, белый текст основной кнопки на #366349 — 6,91:1. Это выше 4,5:1 для обычного текста (1.4.3). Все состояния и подписи графиков отдельно не измерены.
- 2.2.1 разрешает отключение до возникновения лимита. Настройка «Без таймера» есть, поэтому само наличие четырёхминутного режима не считается нарушением. Английские условия маркируются `lang=en`; встроенные английские подписи навыков проверены только частично (3.1.2). Фокус, ошибка и предупреждение об истечении должны оцениваться раздельно.
- 23 теста и 81 проверенный образец MathML не поймали ошибку оператора степени. Хеш-навигация, browser Back, клавиатурные сценарии по оставшимся страницам и полнота альтернатив Canvas требуют более широких тестов.

## Сравнение паттернов

[Lichess — темы задач](https://lichess.org/training/themes) отделяет тренировку по темам от аналитики — в Replay прямую кнопку стоит сохранить. [Khan Academy — уровни освоения](https://support.khanacademy.org/hc/en-us/articles/115002552631-What-are-Course-and-Unit-Mastery) раскрывает, как меняется статус навыка и где искать пробел. В Replay полезно привязать следующий шаг к решению конкретного задания. [Desmos — доступность графиков](https://help.desmos.com/hc/en-us/articles/4404860698253-Introduction-to-Accessibility-Features) демонстрирует, что визуальный смысл можно открыть с клавиатуры альтернативным представлением; для Replay достаточно координат и текстовых свойств, звуковой режим необязателен.

### Проверка форматов ответа

В tests/test_frontend.js добавлена проверка response.kind=sequence с response.options. Шаги имеют неалфавитный порядок ID и собственные подписи. Старый рендерер parts-only её не проходит. Также проверены инструкции пары и интервала, строковые радиоответы и дробные SAT-варианты.

Команды node tests/test_frontend.js и проверки синтаксиса app.js, guide.js, graph.js прошли. Модульные проверки не заменяют браузерный прогон.

### Остатки и ограничения

- Отложенная ошибка другого маршрута исправлена и проверена регрессионным тестом в завершающем проходе ниже.
- Черновик восстанавливается в текущей вкладке; закрытие вкладки может удалить его. Справка объясняет границу. Отправленные ответы хранятся в SQLite.
- Истёкший черновик не отправляется, следующий вопрос получает свой срок.
- Чтение формул скринридером, все клавиатурные маршруты, масштабирования и все варианты графиков этим проходом не проверены.

### Завершение интеграционной проверки 18 ноября

Root исправил отложенную ошибку другого маршрута через проверку routeVersion. Регрессионный тест ожидает ответ HTTP, меняет маршрут, затем возвращает ошибку и подтверждает отсутствие чужого сообщения и перемещения фокуса.

Порядок DOM конструктора теперь начинается с настроек. CSS сохраняет широкую двухколоночную компоновку и размещает настройки выше тем на телефоне. В браузере Tab после заголовка перевёл фокус в количество задач. При 320 px настройки начинались на 175 px, темы на 616 px, scrollWidth=clientWidth=305 px. Добавление 8 класса сохранило выбранную тему 7 класса.

Подтверждение пропуска и завершения встроено в страницу. По умолчанию фокус на «Продолжить решать», Escape скрывает блок и возвращает фокус к исходной кнопке. Отмена не отправляет ответ. Модульная проверка и реальный Escape прошли. Такой блок заменил браузерный confirm, который останавливал используемую автоматизацию.

Проверены английский тест из трёх вопросов без таймера, сохранение «0/» после обновления, aria-invalid и focus=answer при ошибке, затем правильный ответ. Для периодической дроби десятичная аппроксимация отклоняется с пояснением, 1/3 засчитывается, разбор открывается отдельно. На 375 px scrollWidth=clientWidth=375 px.

На 768 px клавиша ArrowRight изменила основание треугольника с 8 до 8,5, таблица координат обновила B(8,5;0). Схема мачты имеет текстовое описание порядка точек, высоты наблюдения и длин. При обычной настольной ширине проверен разбор. Финальный журнал браузера пуст для warn/error. Проверена пауза тура и страница прогресса с несколькими сессиями. Это выборочный прогон, полный скринридерный сценарий остаётся открытым.
