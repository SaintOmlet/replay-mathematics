# Replay Mathematics — аудит безопасности

Проверена фактическая локальная конфигурация: Python `http.server` на `127.0.0.1`, SQLite в каталоге данных и необязательный внешний Groq. Проверки выполнялись с отдельной пустой базой, без реального ключа и без тестов нагрузки на рабочую установку. Результат не является сертификацией ASVS. Применялись [ASVS 5.0.0, официальный реестр требований](https://raw.githubusercontent.com/OWASP/ASVS/v5.0.0/5.0/docs_en/OWASP_Application_Security_Verification_Standard_5.0.0_en.csv) и [OWASP Top 10:2025](https://owasp.org/Top10/2025/). Для стандартной библиотеки использована [документация Python](https://docs.python.org/3/library/http.server.html); отдельного профиля `http.server` в локальном навыке Python нет.

## Проверенные меры

- Host/Origin ограничены адресами localhost, пробный чужой Origin вернул 403, файл вне публичного каталога вернул 404. Для мутаций нужен JSON, тело ограничено 16 КиБ. CORS не открыт универсально. Ограниченная проверка ASVS v5.0.0-2.2.1, 2.2.2, 3.4.2, 3.5.2.
- Запросы SQLite используют параметры, мутация идёт в транзакции. Начало второго запроса с устаревшим индексом не выставляет ответ следующему вопросу. ASVS v5.0.0-1.2.4, 2.3.3.
- JSON сериализуется, ответ ученика экранируется при HTML-выводе, внешний ответ наставника записывается через `textContent`. Формулы идут через разрешённый набор команд браузерного MathML, без запуска TeX или оболочки; штатный тест экранирует HTML. Остались строковые `innerHTML` из шаблонов, поэтому вывод о XSS ограничен просмотренными маршрутами. ASVS v5.0.0-1.2.3, 1.2.8, 3.2.2.
- HTTP подтверждает `nosniff` и `no-store` для проверенных штатных ответов. В localStorage найдена отметка тура, а не ключ, ответы или база истории. ASVS v5.0.0-3.4.4, 14.3.2, 14.3.3.
- Нет сторонних установочных runtime-пакетов приложения и подключаемых CDN-скриптов. Простая проверка шаблонов известных ключей в рабочих исходниках не нашла совпадений. Это не поиск всех форматов секрета/всех версий файла. Ключ Groq читается только сервером из переменной окружения, внешняя конечная точка фиксирована. Скрытый SSRF или утечка ключа не подтверждены.

## Что не подтвердилось или не проверялось

- HTTP request smuggling, XSS, SQL injection, SSRF, утечка ключа и обход браузерных ограничений не подтверждены. Не тестировали прокси, нестандартное HTTP framing на нескольких серверах или разрушительную нагрузку. `http.server` не является подходящим внешним сервером продакшена; отсутствие публичного TLS для loopback не признано проблемой.
- Не проверялись настройки ACL каждого пользовательского профиля, права на резервные копии, сетевое развёртывание, фактические ответы/срок хранения Groq и тесты доступности браузерных защит на разных движках.
- `progress` читает все строки с JSON и строит историю заново. В синтетическом наборе 100/1000/5000 сессий по 10 ответов медианы составили 18,2/177,7/939,7 мс. Это риск роста задержки, а не демонстрация отказа в обслуживании. Нужны индексы и пакетная агрегация, не активное сканирование.

## Повторная приёмка безопасности 18 ноября 2026

Исходные SEC-01–05 выше относятся к выпуску 17 ноября. В текущей версии SEC-02 исправлен читающей транзакцией GET/HEAD и отдельным POST /expire. Действие несёт индекс, повторный или опоздавший запрос не закрывает следующий вопрос. Тест сравнивает содержимое записи до и после истёкшего GET и проверяет HEAD по настоящему HTTP.

Для SEC-03 добавлены CSP с self для скриптов и соединений, object-src none, base-uri none, frame-ancestors none, form-action self, Referrer-Policy no-referrer, nosniff и CORP same-origin. Inline-стили разрешены для существующего интерактивного Canvas и схем, inline-скрипты запрещены. Штатные графики, MathML и элементы управления проверены в браузере, финальный журнал без ошибок. Это ограниченная проверка ASVS 3.4.3, 3.4.5, 3.4.6 и 3.5.3.

Для SEC-04 лимит общий на процесс сервера — 6 обращений за скользящую минуту, 60 за скользящие 24 часа и 2 одновременно. Ошибки провайдера расходуют квоту, слот параллельности освобождается в finally. Тестируются обе временные границы, превышение параллельности и ошибка провайдера. После перезапуска процесса квота обнуляется. Настоящий Groq не вызывался.

SEC-05 исправлен заголовком Server Replay, без версии Python. Соединение имеет таймаут 15 секунд. Host/Origin, размер JSON, разрешённые ресурсы и параметризованные запросы сохранены и входят в тесты.

SEC-01 остаётся ограничением локального запуска. Приложение слушает loopback, история общая, пользовательская авторизация отсутствует. Граница доверия — локальный компьютер. Эта модель раскрыта в README. Сетевой общий доступ требует отдельного проектирования профилей и доступа.

Схема SQLite осталась версии 1. Новая версия прочитала копию существующей базы, все сессии и завершённые уроки совпали до и после, исходный файл совпал по хешу. Кэш прогресса инвалидируется при собственных записях и изменении файла базы другим экземпляром. Замеры и проверка равенства расчётов воспроизводятся через python -B -m audit.probe. Полная сертификация ASVS и проверка всех браузерных атак остаются вне подтверждённого результата.
