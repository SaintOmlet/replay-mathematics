# Replay — математика 7–9 классов

Локальный тренажёр: 121 школьный учебный блок для 7–9 классов и 9 отдельных блоков переноса навыков в SAT. В каталоге 409 семейств и 40 900 индексируемых вариантов, включая 2 700 новых англоязычных SAT-задач; прежние 4 000 англоязычных вариантов также сохранены. Один генератор даёт числовые вариации одного метода. Актуальное покрытие — в [audit/COVERAGE.md](audit/COVERAGE.md).

## Быстрый запуск на Windows

1. Распакуй ZIP в обычную папку. Для запуска нужен [Python 3.10 или новее](https://www.python.org/downloads/).
2. Дважды щёлкни **Start.bat**. Сайт откроется в браузере по адресу [127.0.0.1:8765](http://127.0.0.1:8765). Оставь окно сервера открытым.
3. В **Темах** выбери урок с теорией, примерами и самопроверкой. Кнопка **Задачи** сразу открывает практику. В **Тесте** выбери темы, класс, сложность и время на вопрос. По умолчанию даётся четыре минуты; таймер можно отключить.
4. В **Прогрессе** можно продолжить сессию, открыть разбор, повторить те же ошибки или получить свежие варианты. В разделе **Как пользоваться** есть справка, тур и запуск задачи по её коду.

Для запуска из терминала без открытия браузера выполни `python -B -m backend.server`. Если порт занят, запусти `Start.bat --port 8766`. Для остановки нажми Ctrl+C в окне сервера.

## Уроки, данные и SAT

На уроках есть пошаговые примеры, типичные ошибки и проверочные вопросы. После ответа разбор открывается отдельно. Задания принимают полное алгебраическое выражение, построенный график, таблицу частот, полигон, гистограмму, все корни, объединения промежутков, пары чисел, точные несократимые дроби, выбор и порядок шагов. У поля показан формат.

В тесте время ведёт сервер, включая уход и обновление страницы. Истечение текущего вопроса фиксируется отдельным действием браузера. Следующий вопрос получает свой лимит при открытии. Неотправленный ответ восстанавливается в текущей вкладке для того же вопроса до истечения времени. Закрытие вкладки может удалить черновик. Все незавершённые сессии доступны в каталоге и прогрессе.

Для освоения нужны завершённый урок, минимум шесть новых задач с самостоятельными ответами, точность от 80% и верные решения минимум трёх разных семейств (или всех, если их меньше трёх). Если в теме есть средний уровень, нужны два таких решения, если есть сложный — одно. Подсказки, запрос наставнику и повтор знакомого варианта учитываются отдельно. Старые попытки с неизвестной историей помощи сохраняют эту отметку. У начатой темы показан следующий шаг.

Учебный план сопоставлен с [приказом №399 по алгебре и геометрии Казахстана](https://adilet.zan.kz/rus/docs/V2200029767). Полностью подтверждены 95 из 262 целей, частично — 167; полностью отсутствующих и только объяснённых целей нет. Самостоятельные геометрические построения, свободные доказательства, сбор собственных данных и некоторые общие случаи ещё требуют работы. Нулевое число отсутствующих целей не означает полного курса. Основания — в `audit/algebra.md`, `audit/geometry.md` и актуальном `audit/COVERAGE.md`. Программа НИШ отдельно не сопоставлялась.

Англоязычные задачи авторские, по навыкам из [списка College Board](https://satsuite.collegeboard.org/practice/student-question-bank/math). Ввод дробей и округлённых десятичных сверён с [указаниями Bluebook, осень 2026, с. 7](https://satsuite.collegeboard.org/media/pdf/english-sat-test-directions-bb.pdf#page=7). Для 2/3 принимаются 2/3, .6666, .6667, 0.666 и 0.667. Ответ занимает до пяти символов для положительного числа и шести для отрицательного. Задачи с числом, которое не помещается в поле, получают варианты ответа. Точность Replay не пересчитывается в официальный балл SAT. Полные пробники доступны по ссылкам внутри раздела.

Прогресс хранится в `data/study.sqlite3`. Для переноса истории останови сервер и скопируй папку `data`. Перед заменой приложения сохрани копию этой папки. Версия схемы SQLite осталась 1, новые признаки помощи добавляются в записи сессий. Чтение копии существующей базы проверено с сохранением всех записей. У прежних 19 000 задач сохранены коды и числовые ключи. Для старых ответов с неизвестным временем показывается прочерк.

Уроки, проверка, формулы и графики работают офлайн. Сервер слушает `127.0.0.1`. История общая для локального запуска на этом компьютере. Другие локальные процессы могут обращаться к API. Для совместного доступа из сети понадобится отдельная модель профилей и авторизации.

## ИИ-наставник (по желанию)

Установи переменную окружения `GROQ_API_KEY` **в терминале, из которого запускаешь сервер**. Groq создаёт ключи в [консоли](https://console.groq.com/keys). Для другого поддерживаемого имени модели можно задать `GROQ_MODEL`.

В практике появится кнопка **Спросить ИИ-наставника**. Провайдер получает текст задания, подсказки и вопрос ученика. Без ключа или без интернета доступны встроенные подсказки. Ответы и оценки всегда проверяет локальный код.

На процесс сервера установлены лимиты 6 запросов в минуту, 60 за последние 24 часа и два одновременно. Неудачные обращения расходуют лимит. Перезапуск обнуляет его. Сам запрос наставнику консервативно исключает попытку из самостоятельного освоения, включая ошибку провайдера. Проверки выпуска использовали заглушку провайдера.

## Графики, множества и учебный маршрут

В каталоге добавлены темы построения прямых, преобразований парабол и чтения графиков. Параметры вводятся с клавиатуры, меняются ползунками или перетаскиванием отмеченных точек. Сдаётся полученная функция. Собственный редактор Replay работает офлайн и не требует внешнего ключа. Заданный график отмечается зелёным пунктиром, его формула в заданиях на восстановление скрыта. Координаты доступны в таблице.

Три темы полных множеств решений принимают все рациональные корни и объединения промежутков. Например, корни −2;0;2, промежутки (-inf;2] U [5;+inf), пустое множество ∅ или всю прямую R. Проверка учитывает все компоненты и скобки.

Следующие шаги предлагаются по реальной истории и необходимым основам, доступ к темам свободный. Характерные неверные ответы получают конкретное пояснение после отправки. Список незавершённых занятий свёрнут до последней сессии и раскрывается полностью, история завершённых занятий содержит названия тем.

Текущий выпуск проверен 170 Python-тестами, 140 образцами MathML и тремя JavaScript-наборами интерфейса. Все 163 новых семейства пройдены через HTTP: старт, отсутствие утечки ключей, правильная отправка, результат; ошибки выражения не записывают попытку. В Chrome проверены новый урок, точный дробный ввод и построение гистограммы с разной шириной столбцов. Ранее проверены изменение прямой, отправка и диагностическое пояснение. Полный мобильный/клавиатурный прогон новых экранов, скринридер и проверка с учениками ещё нужны.

Выражения проверяются локально без LLM и `eval`. При требовании раскрыть скобки или разложить на множители одной числовой эквивалентности недостаточно — проверяется и форма ответа. Рациональная эквивалентность сравнивается на общей области определения; самостоятельное нахождение всей ОДЗ остаётся отдельным навыком.

В статистике нужно заполнить все частоты или ординаты. Полигон учитывает неравные расстояния между вариантами. Гистограмма использует настоящую ширину интервалов, а сервер точно сравнивает каждую плотность. Сводный отчёт по SAT — [audit/SAT_ALIGNMENT.md](audit/SAT_ALIGNMENT.md).
